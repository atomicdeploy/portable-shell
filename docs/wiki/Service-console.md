# Service-console composition example

The [consumer catalog](../../examples/service_console_catalog.h) defines 95
presentation states using one [controller](../../examples/console_workspace.c).
It contains synthetic records, labels and routes. It is not linked into the
framework library or normal host executable.

The example demonstrates these reusable components:

For a direct `ps_settings` registry-backed version of the configuration table,
see the [dotted-key settings editor](Settings-editor.md). It shares values and
validation with registry commands; the service catalog remains a separate example.

| Presentation | Framework API | Application responsibility |
| --- | --- | --- |
| Contextual numbered menu | `ps_menu_open`, description and notice callbacks | Items, route destinations and operations |
| Six-tab endpoint controls | `ps_panel_attach`, `ps_panel_open` | Stable IDs, observations and revision-checked writes |
| Configuration and group headings | Typed `ps_control` entries | Ranges, choices, persistence and authentication |
| Staged parameter forms | `ps_form_open` | Field storage, validation, commit/cancel callbacks |
| Documents, guides and long reports | `ps_editor_open` with `PS_EDITOR_READ_ONLY` | Loading the text and sizing its storage |

The new optional `PS_FORM_OVERVIEW` style shows field summaries below the active
question. Tab and Shift-Tab move between validated drafts. The default sequential
question layout remains unchanged. Passwords are masked in both presentations. `ps_form_set_title()` supplies an independent caption without repeating it in field labels.

For numbers such as ports, return `PS_CONTROL_NUMBER_ONLY` in the observed value's
flags. This retains numeric editing and range validation without a percentage
meter. Read-only labels are distinct from locked editable controls.

`ps_panel_active()` returns zero when closed or the active page index plus one.
A consumer can use this after Escape to restore its own parent menu without
intercepting Escape during an unfinished inline edit. `PS_TABLE_BACK_TO_MENU` changes the footer label to match that consumer-owned return path.

## Build and inspect all states

```sh
cmake -DGENERATOR=Ninja -DC_COMPILER=gcc -P tools/rebuild-service-console.cmake
```

Open `build/service-console/gallery/index.html`. Every image is generated by
feeding the actual core and replaying its emitted terminal bytes. To rasterize
with Agave, supply `-DRESVG=/path/to/resvg -DFONT=/path/to/Agave.ttf` and optionally
`-DNERD_FONT=/path/to/AgaveNerd.ttf` before `-P`.

The standard preview workflow also rebuilds four representative captures and
checks them in CI. The dedicated fixture tests all 95 states, menu destinations,
resize, six-tab navigation, typed value updates, form validation and cancellation,
and read-only document protection against text, paste, deletion, undo and save.

## Embed the example controller

```c
/* Keep these objects alive until the session is closed. */
static cw_workspace workspace;
cw_init(&workspace, session, my_screens, PS_COUNT_OF(my_screens));
cw_open(&workspace, "main");

/* On the host's owner loop: */
cw_feed(&workspace, input_bytes, input_count);
cw_tick(&workspace, monotonic_milliseconds);
/* Or feed through ps_feed(), then call cw_dispatch() after it returns. */
```

See [console_workspace.h](../../examples/console_workspace.h) for descriptors and
lifetimes. Shared binding names let a form and table edit the same stored value.
Form drafts are committed only after the entire form is accepted. Panel provider
callbacks queue navigation; they never reenter the session.

This hosted example uses standard C formatting for its local model. The reusable
core still has no OS calls, allocator or required libc dependency. The full
catalog deliberately allocates a generous caller-owned model (112,936 bytes on
the tested x86-64 build) and sets `PS_EDITOR_CAPACITY=16384`; that is an example
choice, not a new framework default. Its session used 56,272 bytes in that build.
Smaller consumers supply smaller screen/model definitions and independently
select framework features and capacities. The synthetic catalog is excluded
from production library and firmware builds.

## Scope of the comparison

This is presentation and interaction evidence, not a complete service backend.
Lifecycle actions acknowledge local requests. Codec order variants demonstrate
editable choices and alternate snapshots, not a codec negotiation implementation.
Reset/delete confirmation choices never delete production data. Log and console
screens show recorded fixture text; live providers can use the existing
[monitor components](Components.md) and asynchronous event loop instead.

To produce an external side-by-side gallery without committing private captures:

```sh
cmake -DDONOR_DIR=/captures/original -DPORTABLE_DIR=/captures/portable \
  -DMAP=/captures/mapping.json -DOUTPUT_DIR=/captures/comparison \
  -P tools/compare-terminal-galleries.cmake
```

The tool verifies every mapped PNG/SVG/ANSI triple, preserves every original
page, and generates a searchable comparison with provenance. Its input schema is
documented at the top of the script. Original captures and private mappings stay
outside the repository.
